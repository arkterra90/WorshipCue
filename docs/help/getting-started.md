# Getting started

WorshipCue keeps presentations, media, and saved service playlists in a local library. Use the three sidebar tabs to switch between **Content Library**, **Service Playlist**, and **Media Library**.

Editing and service preparation do not require a license. Before presenting live, open **Settings → License Activation & Devices…** to activate this installation. See [License activation and devices](licensing.md).

## Install and launch

Use the complete application package supplied for your operating system. On macOS, open the disk image and drag **WorshipCue.app** to **Applications**, then launch the copy in Applications. Keep the MCP companion and runtime files inside the application bundle. A complete deployed package carries its Qt dependencies.

An app labelled **Unsigned development build** has not been signed/notarized as a public release. Use the build approved for your church or organization. Windows release acceptance is still being validated; ask your administrator for the appropriate tested build.

## Prepare a service

1. In **Content Library**, choose **+ New** to create a text presentation, or **Import Song Lyrics…** to bring in a text or ChordPro file. Enter a title and content, review the arrangement, then **Save**.
2. In **Service Playlist**, use **New** to create a saved service. Its name appears in the service selector.
3. Add presentations from Content Library with **Add →** or a double-click. Use **Add to Service** in Media Library for standalone media. Check the displayed destination service before adding content.
4. Drag service items into the required order. Service changes save as you work.
5. Choose **Screens…** to configure audience and stage outputs. **Windowed Preview** lets you check an output on the operator display.
6. Select a service item and slide. In **Show** mode, click the slide to take it live. In **Edit** mode, use **Take Live** when ready.
7. Use **Next** and **Previous**, or Space and the arrow keys, to run the service.

The live slide has a green border and LIVE marker. The live preview shows audience content. **Return to Live** reveals the saved service item associated with the running cue.

## Read help during a service

Open **Help → WorshipCue Help…**. Type words into **Search all help topics** to search article titles and content. Matches are highlighted in the article. Follow related-topic links and use **Back**, **Forward**, or **Home** to navigate. Clear the search to see all topics.

The Help window can stay open alongside the operator window. Click the operator window to resume its keyboard controls. All articles are included with the application and available offline.
