# Presentation navigation

**Show** mode makes slide clicks live. **Edit** mode previews selections and lets you arrange slides. In Edit mode, double-click a slide to open its editor, or use **Take Live** between Previous and Next below the live monitor when ready.

Double-clicking a service item takes its selected or first slide live. The green border and LIVE marker identify the current cue. Use the selector above the right-hand live preview to monitor an audience or stage output. **Up Next / Selected** lets you inspect upcoming or selected slides.

## Move through the service

| Input | Action in Show mode |
|---|---|
| Space, Right, Down, Page Down | Next live slide |
| Left, Up, Page Up | Previous live slide |
| Next / Previous buttons | Move one live slide |
| Escape in operator/output windows | Focus the operator's slides |

Next/Previous cross presentation and standalone media boundaries. At either end, the current first/last slide stays selected. If nothing is live, forward navigation starts the selected slide.

Keyboard navigation is available when the operator or output window has focus. Each press moves one cue. Modal dialogs and popup menus suspend cue navigation and preserve the auto-advance countdown. The Blackout shortcut and MIDI Blackout mapping remain available. In Help, use its reading and search controls, then click the operator window to resume its shortcuts.

## Return to a running cue

**Return to Live** reveals the saved service and item associated with the running copy. If saved content has changed or been removed, WorshipCue explains the difference and keeps the live cue.

Taking a slide captures the service's current saved order. Browsing and reordering saved content keep that running copy in place until the next explicit take. Shared song-text edits made inside WorshipCue can refresh repeated live lyrics.

**Blackout**, **Clear Text**, and **Restore Audience** preserve slide and service position. See Transitions and fades for their timing and media behavior.

## Close WorshipCue during a presentation

Closing the operator window or choosing **Quit WorshipCue** during a live presentation opens a confirmation. **Keep Presenting** is the default. Choose **Quit WorshipCue** to close the live outputs and stop playback.
