# Slide formatting and Looks

**Edit Slide Text…** opens the selected source page's text editor. The toolbar provides font, size, bold, italic, underline, color, and paragraph alignment. Formatting a selection changes those words. With no text selection, formatting applies to the whole slide. Save commits the draft.

## Apply reusable formatting

1. Choose **Presentation → Looks / Reflow…** at the upper-right of the slide workspace or from the slide context menu.
2. Select source pages with Command-click on macOS, Ctrl-click on Windows, or Shift-click for a range.
3. Use **Capture Slide Formatting**, or choose a saved Look. Set font, size, style, text color, alignment, margins, and padding.
4. In **Layout / Background**, choose the presentation background, a color, or an image from the Background Library.
5. **Save as Look…** creates a named reusable Look. **Apply to Selected Slides** assigns it to chosen pages. **Apply to Presentation** establishes the shared presentation Look.
6. Review the preview, then **Save**.

**Keep slide text formatting overrides** retains existing rich text styling alongside the Look's layout and background. Repeated song-section occurrences use the same source-page formatting.

## Resolve overflow

When text exceeds its measured text box, the **Text Overflow** dialog offers **Preview Automatic Split…**, **Fit Text**, or cancellation. Review split pages before **Apply Split**. Splitting preserves source text and reading order, section associations, and media references.

**Undo Look / Split** and **Redo Look / Split** restore draft operations. Cancel discards the presentation draft. Named Looks saved through **Save as Look…** remain reusable.

After saving, take a slide live to apply its saved appearance. Later overflowing lyric edits produce warnings and safety fitting. Open Looks / Reflow to review a split or explicit fit.
