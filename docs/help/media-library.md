# Media Library

The **Media Library** stores individual images, videos, and audio files. Service entries reference those assets directly.

## Import and organize

1. Choose **Import Media…** and select files.
2. Review the filenames and audio/video loop choices. **Also create a slide presentation from this batch** makes a presentation when the files need to play as slides.
3. Choose **Add imported items to the current service** if required, then **Import Media**. The destination is the service selected when import starts.
4. Use **Rename / Organize…** to change the display name, folder label, or looping. Files keep their managed storage paths.

Search asset names or folder labels. Selecting an asset displays metadata such as type, size, dimensions, modification date, import date, and managed path. Older assets can have an unknown import date.

## Preview and present

**Preview…** opens a local preview. For audio/video, choose **Play Preview** to start playback. Closing the preview stops it.

Use **Add to Service**, or drag an asset onto the **Service Playlist** tab, to add it to the selected service. Dropping on an item inserts before that item. Repeated entries share the asset and file.

Use **Take Live** or the asset's **Take Live** context action to trigger it directly. The live transport provides pause/play, restart, mute, and looping for playable audio/video.

## Delete an asset

**Delete from Media Library…** asks for confirmation. Saved services and presentations protect their referenced assets. Ordinary deletion retains managed files. Use Library Cleanup to review and reclaim file storage.

Decoding depends on the installed Qt runtime and operating system. Animated images import as stills.
