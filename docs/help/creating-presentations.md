# Creating presentations

Presentations hold editable slides for songs, sermon points, announcements, and other text. Standalone media belongs in the Media Library.

## Create text slides

1. In **Content Library**, select **+ New**.
2. Enter the presentation title. Create and name its sections, then enter the text for each section's slide.
3. Use **Add Slide** for additional pages. For a sermon or announcement, custom section names can identify a title, scripture, points, or notices.
4. Select a section and choose **Add Section →** to include it in the arrangement. Put the section references in the required playback order.
5. Review the preview and choose **Save**. The presentation becomes available in Content Library.

For prepared lyrics, choose **Import Song Lyrics…** in the sidebar or File menu. Import UTF-8 text or ChordPro, review the resulting slides, and save. Blank lines, section headings, and `---` separators create slide breaks. Matching repeated headings and lyrics share a section.

## Edit and style

Select a presentation and choose **Edit**, or select a source slide and choose **Presentation → Edit Slide Text…** from the workspace header. Save commits the draft. Cancel discards draft edits.

Use **Looks / Reflow…** to apply reusable formatting. Use **Background Library…** to assign an included background or import a still image. Add the saved presentation to a service with **Add →**.

An AI client connected through **Settings → AI / MCP Setup…** can also create song and sermon presentations from supplied content.
