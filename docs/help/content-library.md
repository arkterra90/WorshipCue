# Content Library

Select **Content Library** in the sidebar to browse saved presentations. Search by title or lyric text. Command+F on macOS or Ctrl+F on Windows opens the library search when the operator window has focus.

Select a presentation to inspect its source slides in the workspace. **Edit** opens its editor. **Presentation → Song Sections / Arrangements…** opens the structured song editor. The workspace header's **Presentation** menu also provides **Edit Slide Text…**, **Looks / Reflow…**, and **Timing & Transitions…** for the selected presentation or source slide.

## Reuse content

Choose the destination in the saved service selector. **Add →** or a double-click adds a reference to that presentation. Repeating the action adds another service occurrence. Each occurrence can have its own slide order.

Saved presentation text, backgrounds, Looks, and presentation timing are shared by its service occurrences. Duplicating a presentation creates independent text and section sources while sharing managed media files.

## Remove content

Library deletion requires confirmation and removes that presentation from saved services. Review the affected content before confirming. The running live snapshot retains its captured service.

For an age-based review with reversible removal, use **Settings → Library Cleanup / Storage…**. That workflow explains protected references and offers Recovery.
