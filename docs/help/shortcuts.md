# Keyboard reference

## Operator and output windows

| Key or control | Action |
|---|---|
| Space, Right, Down, Page Down | Next slide in Show mode |
| Left, Up, Page Up | Previous slide in Show mode |
| Escape | Focus the operator's slide controls |
| {{blackout-shortcut}} | Toggle audience Blackout |
| {{clear-shortcut}} | Toggle audience Clear Text |
| Command+F on macOS / Ctrl+F on Windows | Focus Content Library search |
| {{help-shortcut}} | Open WorshipCue Help |

Blackout and Clear Text above show the configured audience shortcuts. Use **File → Keyboard Shortcuts…** to change them. This reference updates when the new shortcuts are saved.

Navigation shortcuts work in Show mode when the operator or output window has focus. Typing fields, modal dialogs, and combo-box editing receive their own keys. In Edit mode, arrow keys select slides.

## Editing and service selection

| Key | Context and action |
|---|---|
| Option/Alt+Return | Split at Cursor in a song section's lyric editor |
| Command+A on macOS / Ctrl+A on Windows | Select all service items while the playlist has focus |
| Command+Z on macOS / Ctrl+Z on Windows | Undo Bulk Transitions while the playlist has focus |
| Platform Redo shortcut shown in Edit | Redo Bulk Transitions while the playlist has focus |
| Shift-click | Select a range of service items or source pages |
| Command-click on macOS / Ctrl-click on Windows | Select separate service items or source pages |

## Help window

| Key | Action |
|---|---|
| Command+F on macOS / Ctrl+F on Windows | Focus and select the help search |
| {{back-shortcut}} | Previous help article |
| {{forward-shortcut}} | Next article in help history |
| Escape | Close Help |

Use Tab to move between help controls and the reader. Arrows and Space operate the focused Help control. Click the operator window to resume its keyboard commands.
