# Songs and arrangements

A song contains unique sections such as Verse 1, Chorus, Bridge, or a custom name. An arrangement references those sections in playback order. Repeated Chorus entries share the same lyrics.

## Edit sections

1. Select a text presentation and choose **Presentation → Song Sections / Arrangements…**, or choose **+ New**.
2. Use **Add** in the section list to create a section. Choose a suggested name or type a unique custom name.
3. Select one of its labelled slides to edit the lyrics. **Add Slide**, **Duplicate**, and **Split at Cursor** create pages. Option/Alt+Return also splits at the cursor.
4. Drag slides or use ↑/↓ to order them within the section. Drag sections to reorder source groups.
5. **Remove** confirms page or section removal. Each section retains at least one slide.

Existing flat presentations acquire section groups when saved through this editor. Section edits keep rich formatting on unchanged pages. Changed or manually split lyrics use plain text until styled again.

## Build an arrangement

Select a section and choose **Add Section →**. Repeat the action for another reference to the same section. Drag the arrangement list to change the sequence. Its **Remove** button removes one occurrence.

**New**, **Copy**, **Rename**, and **Delete** beside the arrangement selector manage named arrangements. Select the arrangement and **Save** to make it the song's playback order. The preview updates as lyrics and references change.

Editing a shared source page updates its repeated occurrences. Saved custom service orders follow complete section groups through supported structural changes. Removing a page used by a partial custom order requires resetting that order first.

Shared text edits made in WorshipCue can refresh live lyrics while preserving the cue position. An explicit take captures structural or arrangement-order changes. External MCP edits appear in saved content and are captured on the next take.
