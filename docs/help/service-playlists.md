# Service playlists

A saved service is an ordered collection of presentations and standalone media. Select **Service Playlist** in the sidebar to work with its order.

## Build the order

1. Use **New** to create a service, **Rename** to change its name, or **Copy** to reuse an earlier service and its arrangements.
2. Select the destination service before adding Content Library presentations or Media Library assets.
3. Drag entries into order, or use the arrow buttons and context menu. Several selected entries move together in their existing order.
4. **Duplicate** adds another occurrence. **Remove** removes the selected service entry.

Service changes save after each successful operation. The selected service and its order are restored when WorshipCue opens again.

## Arrange slides for one occurrence

Select a presentation entry. In **Edit** mode, drag its slide cards or use their context menu to change that occurrence's playback order. **Reset to Song Order** returns it to the presentation's saved arrangement or natural source order.

Default structured-song entries follow the song's active arrangement. Explicit service slide orders retain their chosen source pages, including repeats.

## Run the saved service

Switch to **Show** mode and take a slide live. WorshipCue captures the entire service for navigation, including upcoming items. Next/Previous run through this captured copy. Browsing another service and changing its saved order keep the running cue in place. An explicit take captures the newly saved order.

At the beginning or end, manual navigation holds the first or last slide. Automatic timing holds at the end of its presentation, or loops that presentation when configured.
